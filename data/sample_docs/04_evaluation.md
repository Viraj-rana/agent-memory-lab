# Evaluating Memory Systems

You can evaluate a memory stack quickly without a huge benchmark suite.

Start with a tiny golden set of questions and expected evidence:
1. Text hit — does the answer mention required concepts?
2. Citation hit — does the answer cite the right document?
3. Abstain rate — does the system refuse when memory is missing?

Track hit rates over time as you change chunking, retrieval, or prompts.
A 10-question suite that runs in seconds is more useful than an unread paper
benchmark. Improve the suite only after the basic loop is reliable.
