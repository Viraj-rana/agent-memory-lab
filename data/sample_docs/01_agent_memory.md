# Agent Memory

Agent memory is durable context an AI agent can store and reuse across sessions.
Without memory, every run starts from zero: past decisions, fixes, and preferences disappear.

Good agent memory captures three layers:
1. Episodes — what happened in a session
2. Facts — stable truths extracted from episodes
3. Procedures — reusable playbooks the agent learned

Memory matters because agents that remember ship faster, repeat fewer mistakes,
and can explain why they chose a path. In product terms, memory turns a chatbot
into a teammate that compounds experience.
